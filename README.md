# UniqueSystem HR Dashboard

A Power BI dashboard that analyses employee details, salary and attendance
for UniqueSystem.

## Files
- [HR Analytics Report.pbix](HR%20Analytics%20Report.pbix): Power BI report
- [UniqueSystem HR Dashboard.pdf](UniqueSystem%20HR%20Dashboard.pdf): PDF of the dashboard
- [data/](data/): source Excel files

## Data cleaning (Power Query)
- Appended 2020, 2021 and 2022 sheets
- Removed duplicate Employee IDs
- Capitalised employee names
- Converted Salary to a number
- Added Age, Age Group, Experience Level and Join Year

## Visuals
Cards, bar chart, combo chart, stacked column, pie, donut, map,
country slicer and employee table.

## Tools
Power BI Desktop, Power Query, DAX
